# Promptory: Prompt, Then Verify

An onboarding tool that helps beginners write a clear coding prompt (with clarifying questions from Claude) and then check the code they get back by writing their own tests.

**Open it:** https://aadityabahl13.github.io/promptory/

To get Claude's live questions, paste your own Anthropic API key in the settings (gear icon). It is stored only in your browser and sent only to Anthropic. Without a key, choose "Use scripted questions" to try the full flow.

Built for INFO 3160.
